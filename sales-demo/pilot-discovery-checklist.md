# Company pilot discovery checklist

Use this checklist to turn a successful demo into a scoped pilot. Record the buyer's answers; do not assume the public prototype already provides these capabilities.

## Workflow and users

- Which sites, laboratories, and teams would use the system?
- Who creates drums, scans labels, reviews uncertain results, and approves the final inventory?
- How many containers and drum records are typical per shift or week?
- What happens when a label is damaged, missing, or difficult to read?
- Which exports, reports, or hand-offs are required?

## Data and chemical identity

- Which chemical data sources are accepted by the organisation?
- Which fields must be captured and which are optional (for example, concentration, CAS, UN number, lot, expiry, quantity, package size, and state)?
- What confidence or review rules should trigger manual confirmation?
- How will users report and correct OCR errors?
- Are label images retained, and if so, for how long and where?

## IT, security, and operations

- Is SSO required? Which identity provider and role model?
- Must several users see and edit the same inventory in real time?
- What audit history, data residency, backup, and deletion controls are required?
- Which hosting environment and network restrictions apply?
- Which systems need integration (waste contractor, EHS, LIMS, ERP, or document management)?
- What accessibility, mobile-device, and offline requirements apply?

## Validation and pilot success

- Who will provide a representative, approved set of label images for evaluation?
- Which languages, manufacturers, bottle types, and camera conditions should be included?
- What name-reading accuracy is required, and how will it be measured?
- Which safety and compliance reviews are mandatory before operational use?
- What is the pilot group, duration, support model, and success threshold?

## Proposed next step

Agree a short discovery workshop, a data-handling plan, an acceptance set of label images, and a written pilot scope before using the tool with operational inventory.
